## ABOUT THE PROJECT
* The “Exoplanets of the Universe” project successfully demonstrates the application of data analytics and visualization techniques to a complex, real-world astronomical dataset. By utilizing data from the NASA Exoplanet Archive, the project transforms raw scientific data into meaningful insights through interactive and visually engaging Power BI dashboards.
Throughout the analysis, key trends in exoplanet discoveries were identified, highlighting a significant increase in confirmed planets over recent years. 
* This growth reflects the impact of advanced space missions and improved detection technologies. The comparative study of discovery methods revealed that techniques such as Transit and Radial Velocity dominate current discoveries, while methods like Imaging provide deeper observational detail despite fewer detections.
The project also explored the relationship between stellar properties and planetary characteristics, offering valuable insights into planetary formation and system diversity.
* Additionally, the use of AI-driven visuals helped identify the most influential factors affecting exoplanet detectability, reinforcing existing scientific theories while presenting them in an accessible format.
From a technical perspective, effective data preprocessing ensured accuracy and reliability in analysis.
* The creation of supporting datasets enabled dynamic image-based visuals, enhancing user engagement and storytelling. The final dashboard successfully combines analytical depth with intuitive design, demonstrating that Power BI can be effectively used beyond traditional business domains, extending into scientific and research-oriented applications.
Overall, this project enhanced practical skills in data cleaning, modelling, analysis, visualization, and storytelling.
* It serves as a strong example of how modern BI tools can simplify complex datasets and communicate insights effectively to diverse audiences.
